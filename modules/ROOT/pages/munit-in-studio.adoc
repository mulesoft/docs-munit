= MUnit in Anypoint Studio
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

MUnit is fully integrated with Anypoint Studio, letting you create, design, run, debug, and view results of MUnit tests directly from the IDE. You can configure tests visually on the canvas or write XML in the editor, and view test results and coverage metrics from the MUnit panel.

For full instructions, see xref:studio::test-with-munit-in-studio.adoc[Testing Projects with MUnit in Studio].
