= MUnit Utils
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]
:page-deployment-options: acb-ide, studio-ide

MUnit Utils are utilities that let you mock external system connections in MUnit tests, making your test suites portable and independent from external infrastructure. Use them to implement in-memory database and FTP servers, or manage temporary queues during test runs.

[%header%autowidth.spread,cols="a,a"]
|===
| Utility | Description
| xref:db-util.adoc[] | Implement a DB server in your local environment to test connections.
| xref:ftp-util.adoc[] | Implement an FTP server in your local environment to test connections.
| xref:queue-processors.adoc[Queue Event Processors] | Manage temporary queues during your test runs.
|===
