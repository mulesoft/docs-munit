| xref:use-environment-properties-on-tests-cookbook.adoc[] | Loading different environment values to your MUnit tests.
| xref:utility-classes-cookbook.adoc[] | Using custom Java classes in your MUnit tests.
| xref:ftp-server-cookbook.adoc[] | Configuring an FTP utility to test your FTP server connections.

| xref:test-flow-with-scheduler-cookbook.adoc[] | Testing a flow that is triggered by a scheduler.
| xref:test-recorder-examples.adoc[] | Using the MUnit test recorder.
| xref:test-processor-that-uses-target-variable.adoc[] | Ensuring that the assertions check the content of the stored variable.
